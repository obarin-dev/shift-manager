# ホーム画面（TOP）詳細設計

## 概要

このドキュメントは、ログイン後に表示するホーム画面（TOP）の詳細設計をまとめたものです。
現時点では管理者向け UI を中心に実装しており、勤務表作成者・職員向けはプレースホルダー表示です。

## 画面情報

| 項目 | 内容 |
| --- | --- |
| 画面名 | ホーム画面 |
| パス | `/home` |
| 実装ファイル | `src/app/home/page.tsx` |
| 認証 | 未接続（ダミー認証で `?role=` により表示を切り替え） |

## 目的

- ログイン直後に、その日・その役割で必要な情報へすぐアクセスできるようにする。
- 管理者には、特別な予定の確認と、主要業務（勤務表・体制表・園管理）への導線を提供する。

## メインエリア（管理者）

### 本日の予定

| 項目 | 説明 |
| --- | --- |
| 見出し | 本日の予定 |
| 日付 | 当日の日付（曜日付き） |
| 一覧 | 特別な予定のみを時刻順に表示 |

**表示方針**

- 開園・給食・おやつなど、毎日ある通常の流れは表示しない。
- わくわく体育、避難訓練、誕生日会打ち合わせ、昼勉強会、療育など、**行事・打ち合わせ・特別活動**のみ表示する。
- 1件あたり「時刻 + 内容」を横長の枠で表示する。
- 表示件数が枠の高さを超える場合は、一覧部分を縦スクロールする。

**ダミーデータ（UI 確認用）**

| 時刻 | 内容 |
| --- | --- |
| 9:30 | わくわく体育 |
| 10:30 | 避難訓練 |
| 11:00 | 誕生日会打ち合わせ |
| 12:30 | 昼勉強会 |
| 14:00 | こうちゃん療育 |

### 機能カード

画面上部の予定エリアの下に、3枚のカードを横並び（狭い画面では縦積み）で表示する。テキストはカード上端から配置する。

| カード | 説明 |
| --- | --- |
| 勤務表作成 | 希望休を踏まえて勤務表のたたき台を作成し、確定まで進める |
| 体制表作成 | クラス別・時間帯別の職員配置を確認し、体制表として整える |
| 園管理 | 園情報、クラス、職員の登録・招待などを管理する |

「園管理」カードから `/nursery` へ遷移する。勤務表作成・体制表作成は未接続。

### ヘッダー右上

- ログインユーザーの役割名をチップ表示する（例: 管理者）。
- 「ダミーモード」表示は行わない。

## メインエリア（勤務表作成者・職員）

仮ホームとして、見出し・説明文・機能カード 3 枚を表示する。管理者向けの「本日の予定」エリアは表示しない。

| 役割 | カード例 |
| --- | --- |
| 勤務表作成者 | 希望休一覧、勤務表作成、配置チェック |
| 職員 | 希望休入力、勤務表確認、お知らせ |

## 今後の実装

- 本日の予定を API / DB から取得する（特別な予定フラグまたはカテゴリでフィルタ）。
- 予定が 0 件のときの空状態表示。
- 勤務表作成・体制表カードから各画面への遷移接続。
- 本番認証・セッション管理とログアウト処理。
- 勤務表作成者・職員向けホームの UI を役割に合わせて刷新。
- 園設定・配置基準・招待管理など、サイドバーへの追加メニュー。
