# 勤務表作成（月間グリッド） 詳細設計

## 概要

このドキュメントは、**勤務表作成画面**（`/shifts`）の詳細設計です。  
MVP では **月間のマトリクス表** を表示し、**AI 作成**と**手動編集**を行えるようにします。

## 画面情報

| 項目 | 内容 |
| --- | --- |
| 画面名 | 勤務表作成（月間） |
| パス | `/shifts` |
| 親画面 | ホーム `/home`、サイドバー「勤務表作成」 |
| 対象役割 | 管理者、勤務表作成者（MVP は同一 UI） |

## レイアウト（マトリクス表）

| 軸 | 内容 |
| --- | --- |
| **X 軸（横・上段）** | 対象月の**日付**（1 日〜月末）。曜日・日付番号を表示 |
| **Y 軸（縦・左列）** | 登録済み**職員の苗字**（`MOCK_STAFF` の `name` から抽出） |
| **セル** | その職員・その日の勤務区分（早番 / 日勤 / 遅番 / 延長 / 休） |

```
        │ 5/1 │ 5/2 │ 5/3 │ …
────────┼─────┼─────┼─────┼──
 山田   │  早 │  日 │  休 │
 佐藤   │  日 │  遅 │  日 │
 …      │     │     │     │
```

- 左列（苗字）・上段（日付）は **sticky** で、横スクロール時も見える
- 月の前後移動で対象年月を切り替える

## 含む（MVP）

- 月間グリッドの表示
- 有効な職員のみ行に表示（`is_active === true`）
- 勤務区分の略称表示（早 / 日 / 遅 / 延 / 休）
- 土日の日付ヘッダーを色分け
- **AI で作成**ボタンで、対象月の勤務案を自動生成（モック）
- 各セルの**プルダウン**で勤務区分を手動選択（休 / 早 / 日 / 遅 / 延）
- **印刷**ボタンで月間勤務表を A4 横置きで印刷（サイドバー・操作 UI は非表示）

## 含まない（今後）

- 希望休・園カレンダーとの自動整合チェック
- 確定・公開・CSV 出力（`docs/export-design.md` 参照）

## データ（モック）

| 型 / 定数 | ファイル | 説明 |
| --- | --- | --- |
| `ShiftAssignment` | `src/lib/mock-shift-schedule.ts` | 職員 × 日付 × 区分 |
| `INITIAL_MONTHLY_SHIFT_SCHEDULE` | 同上 | 初期の 2026 年 5 月分 |
| `getStaffSurname` | 同上 | 表示名から苗字を取得 |

本番では将来 `data-design.md` の **勤務表** / **勤務枠** にマッピングする想定です。

※現状はDBに永続化せず、`src/lib/mock-shift-schedule.ts` でモックとして扱っています。
