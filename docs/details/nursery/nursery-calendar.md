# 行事カレンダー 詳細設計

## 概要

このドキュメントは、園管理配下の **行事カレンダー**（`/nursery/calendar`）の詳細設計です。

月/週/日で、休園日・臨時の開園時間・行事（打ち合わせ含む）を登録します。勤務表作成の前提データになります。

**データ:** 基本設定の休日設定と同じ `calendar_entry` テーブルを参照・編集する（[holiday-and-calendar-data.md](./holiday-and-calendar-data.md)）。

## 画面情報

| 項目 | 内容 |
| --- | --- |
| 画面名 | 行事カレンダー |
| パス | `/nursery/calendar` |
| 親画面 | 園管理ハブ `/nursery` |

## 含む（MVP）

- **表示切替タブ**：月 / 週 / 日（初期表示は **日**）
  - **月**：月間グリッド。日付クリックで **日** 表示へ
  - **週**：日曜始まりの1週間。日付クリックで **日** 表示へ。予定クリックで編集
  - **日**：その日の予定一覧・追加・編集（メインの操作画面）
- ナビゲーション：表示に応じて 前月/翌月・前週/翌週・前日/翌日
- 下部の凡例・予定リストは表示しない（日ビューで完結）
- 月/週グリッドは横幅不足時に横スクロールで表示（表示崩れ防止）
- 予定の種類：休園 / 臨時の開園時間 / 行事

## 含まない

- 園の基本情報・勤務区分マスタ（`/nursery/settings` に分離）
