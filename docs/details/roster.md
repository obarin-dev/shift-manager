# 体制表作成 詳細設計

## 概要

このドキュメントは、**体制表作成画面**（`/roster`）の詳細設計です。  
**1日分**のクラス別・時間帯別の職員配置をマトリクスで表示します。

## 画面情報

| 項目 | 内容 |
| --- | --- |
| 画面名 | 体制表作成 |
| パス | `/roster` |
| 親画面 | ホーム `/home`、サイドバー「体制表作成」 |
| 対象役割 | 管理者、勤務表作成者（MVP は同一 UI） |

## レイアウト（マトリクス表）

| 軸 | 内容 |
| --- | --- |
| **Y 軸（縦・左列）** | **時間行 + 備考行**（時間行は時刻編集可、備考行は左端も記入可） |
| **X 軸（横・上段）** | **クラス名**（園管理のクラスマスタ） |
| **セル** | その時間帯・クラスに配置する職員の**苗字**（複数可） |

```
         │ 0歳児 │ 1歳児 │ 2歳児 │ 3・4・5歳 │
─────────┼───────┼───────┼───────┼───────────┤
  7:00   │  —    │ 山田  │  —    │ 鈴木      │
  8:00   │  —    │ 山田  │ 伊藤  │ 鈴木      │
  …      │       │       │       │           │
 19:00   │  —    │ 佐藤  │  —    │ 高橋      │
```

- 画面上部に**対象日**（初期表示は**今日**）。前日 / 今日 / 翌日で切替
- クラス列ヘッダーに園児数を併記（「今日」は空欄初期値）

## 含む（MVP）

- 日別体制表グリッドの表示（モック配置）
- クラス一覧は `INITIAL_MOCK_CLASSROOMS` を使用
- 配置職員はクラスの主担当・その他担当からモック生成（日付切替で再生成）
- **セル編集**: 職員名の表示箇所をコンボボックス（`<select>`）で変更。未配置は「—」
- 同一セルに2名いる場合はコンボボックスを2つ表示（重複選択は不可）
- **全クラス**: 列ヘッダーに**今日の園児数**を入力（初期値は空欄、手書き運用に対応）
- **配置欄数の増減**: 各セルで `＋ / −` ボタンにより職員コンボボックスの表示数を増減（最小 0）
- **備考行**: 行追加時に「スケジュール行 / 備考行」を選択。備考行は各クラスセルと左端セルに記入可能
- **行操作**: 各行の時間列左下に `＋ / −` を配置（`＋` は行直下に追加、`−` は行削除）
- **ヘッダー操作**: 時間ヘッダー左下の `＋` から先頭行として追加
- **本日の行事表示**: 体制表上部に園カレンダーから当日行事を表示
- **時間軸の柔軟設定**: 時間セルを直接編集し、時間行/備考行を任意追加可能
- **リサイズ**: 行高・列幅をドラッグ調整可能
- **印刷**: A4縦向き。「本日の行事」から下を印刷
- **保存/読込**: 日付単位で体制表を保存・再読込（`/api/roster`）
