# 権限設計

## 概要

このドキュメントは、保育園向け勤務表管理システムにおける利用者の役割と操作権限を整理したものです。
勤務表、希望休、職員情報、配置基準などは扱う情報の重要度が高いため、役割ごとにできる操作を明確にします。

## 役割一覧

| 役割 | 説明 |
| --- | --- |
| 管理者 | 園全体の設定、職員管理、勤務表管理、権限管理を行う |
| 勤務表作成者 | 希望休の確認、AI勤務表作成、修正、確定、公開を行う |
| 職員 | 自分の希望休を入力し、公開された勤務表を確認する |

## 補足ルール

| 表記 | 意味 |
| --- | --- |
| yes | 操作または閲覧できる |
| no | 操作または閲覧できない |
| view | 閲覧のみできる |
| own | 自分に関する情報のみ閲覧または操作できる |
| own_limited | 自分に関する一部項目のみ編集できる |
| published | 公開済みの勤務表のみ閲覧できる |

## 職員情報の権限

### 職員本人が編集できる項目

- 自分の連絡先
- ふりがな
- 勤務希望の補足メモ
- 通知を受け取る連絡先

### 管理者のみ編集できる項目

- 氏名
- 雇用区分
- 職種
- 保育士資格などの資格情報
- 担当可能クラス
- 勤務可能曜日、時間帯
- 早番、遅番、延長保育の対応可否
- 在籍状態

職員本人が編集できる項目は、勤務表作成や配置基準に直接影響しない情報に限定する。
勤務表作成に影響する情報は、誤入力を防ぐため管理者のみ編集できるようにする。

## 希望休の権限

### 職員

- 自分の希望休を入力できる。
- 自分の希望休を提出前であれば修正できる。
- 提出後の修正は、提出期限内かつ園の設定で許可されている場合のみできる。
- 他の職員の希望休は閲覧できない。

### 勤務表作成者

- 全職員の希望休提出状況を確認できる。
- 希望休を代理入力できる。
- 希望休を承認、却下できる。
- 勤務表作成に必要な範囲で希望休を閲覧できる。

### 管理者

- 希望休に関するすべての操作ができる。
- 提出期限や修正可否の設定を変更できる。

## AI勤務表作成の権限

- AI勤務表作成は、管理者と勤務表作成者のみ実行できる。
- AIに渡す作成条件を変更できるのは、管理者と勤務表作成者のみとする。
- AI作成案は、確定または公開されるまで職員には見せない。
- AI作成案の警告や調整理由は、管理者と勤務表作成者のみ閲覧できる。
- AI作成案を確定する前に、人による確認を必須とする。

## セキュリティ方針

- 職員は他の職員の希望休や個人情報を閲覧できない。
- 職員はAI作成中の勤務表を閲覧できない。
- 公開前の勤務表は管理者と勤務表作成者のみ閲覧できる。
- 確定済み勤務表を修正可能状態に戻す操作は管理者のみできる。
- 重要な操作は操作履歴を残す。

## 操作履歴を残す対象

| 操作 | 履歴に残す内容 |
| --- | --- |
| 職員登録・編集 | 操作者、対象職員、変更内容、日時 |
| 配置基準変更 | 操作者、変更前後の内容、日時 |
| 希望休代理入力 | 操作者、対象職員、入力内容、日時 |
| AI勤務表作成 | 操作者、作成条件、対象年月、日時 |
| 勤務表修正 | 操作者、変更前後の勤務枠、日時 |
| 勤務表確定 | 操作者、対象年月、日時 |
| 勤務表公開 | 操作者、対象年月、日時 |
| 確定後修正 | 操作者、修正理由、変更内容、日時 |
