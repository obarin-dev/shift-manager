# 印刷・CSV設計

## 概要

このドキュメントは、保育園向け勤務表管理システムにおける印刷と CSV 入出力の設計をまとめたものです。
勤務表はシステム上で確認するだけでなく、職員室への掲示、管理者確認、紙での配布、外部ツールとの連携に使えるようにします。

## 出力の目的

- 職員室などに紙で掲示できる勤務表を作る。
- 職員が自分の勤務を確認しやすい形式で出力する。
- 管理者が配置基準や勤務偏りを確認しやすい形式で出力する。
- 勤務表データを CSV でエクスポートし、表計算ソフトで確認できるようにする。
- 必要に応じて CSV から職員情報や勤務表を取り込めるようにする。

## 出力形式

| 出力形式 | 用途 |
| --- | --- |
| 月間勤務表印刷 | 1か月分の勤務表を紙で確認する |
| 日別勤務表印刷 | 1日のクラス別、時間帯別配置を紙で確認する |
| 職員別勤務表印刷 | 職員ごとの勤務予定を確認する |
| 掲示用勤務表印刷 | 職員室などに掲示する |
| 管理者用勤務表印刷 | 配置基準、警告、メモを含めて確認する |
| CSVエクスポート | 勤務表や職員情報を外部で利用する |
| CSVインポート | 職員情報や勤務表データを取り込む |

## 印刷レイアウト

| 項目 | 説明 |
| --- | --- |
| 対象年月 | 印刷対象の年月 |

| 日付 | 列に表示する日付 |

| 園児数 | クラスごとの園児数 |

### 職員別勤務表

| 項目 | 説明 |

| 職員名 | 対象職員 |

| 勤務日 | 勤務する日 |

## 印刷タイプ

| 印刷タイプ | 対象者 | 表示内容 |
| --- | --- | --- |
| 職員向け | 職員 | 公開済みの勤務表、自分の勤務、必要最低限の配置情報 |
| 管理者向け | 管理者、勤務表作成者 | 配置基準、警告、希望休との矛盾、メモ |
| 掲示用 | 全職員 | 個人情報を抑えた月間または日別勤務表 |

## 印刷前確認

印刷前には以下を確認できるようにします。

- 対象年月または対象日
- 印刷タイプ
- 表示する項目
- 用紙サイズ
- 縦向き、横向き
- 余白
- 改ページ位置
- 個人情報を含むかどうか

## CSVインポート

### 対象データ

| 対象 | 用途 |
| --- | --- |
| 職員情報 | 初期登録や一括更新に使う |
| クラス情報 | クラス名、年齢区分、園児数を取り込む |
| 希望休 | 別管理している希望休を取り込む |
| 勤務表 | 外部で作成した勤務表を取り込む |

### インポート時の確認

- 必須項目が入力されているか。
- 日付、時刻の形式が正しいか。
- 職員IDまたは職員名が既存データと一致するか。
- クラス名が既存データと一致するか。
- 勤務時間が園の開園時間、延長保育時間の範囲内か。
- 希望休や勤務不可時間と矛盾しないか。
- 配置基準を満たしているか。

### インポート結果

| 結果 | 説明 |
| --- | --- |
| 成功 | すべての行を取り込めた |
| 一部成功 | 一部の行だけ取り込めた |
| 失敗 | 取り込みできなかった |

インポート失敗時は、行番号、項目名、エラー内容を表示します。

## 出力履歴

出力や取り込みを行った場合は、以下の履歴を残します。

| 項目 | 説明 |
| --- | --- |
| 実行日時 | 出力または取り込みを行った日時 |
| 実行者 | 操作したユーザー |
| 対象年月または対象日 | 対象の勤務表 |
| 出力形式 | CSV、印刷など |
| 印刷タイプ | 職員向け、管理者向け、掲示用など |
| ファイル名 | CSVの場合のファイル名 |
| 結果 | 成功、失敗、一部成功 |

## 個人情報の扱い

- 掲示用には連絡先などの個人情報を表示しない。
- 職員向けには必要最低限の勤務情報のみ表示する。
- 管理者向けのみ希望休理由や詳細メモを表示する。
- CSVエクスポートは管理者と勤務表作成者のみ実行できる。
- 出力履歴を残し、誰がいつ出力したか確認できるようにする。
